# NetGuard - Network Intrusion Detection System

NetGuard is a network traffic monitoring and intrusion detection system developed using Python. The system captures live network packets and analyzes protocols such as TCP, UDP, DNS, and ICMP to monitor network activity.

NetGuard includes a rule-based detection engine that identifies suspicious network behavior such as port scanning and abnormal ICMP traffic. When suspicious activity is detected, the system generates security alerts containing the source IP, alert type, severity, and detection information.

Captured network traffic and security alerts are stored using SQLite and displayed through a Flask-based web dashboard. The dashboard provides packet statistics, protocol distribution, recent network traffic, and detected security alerts.

## Installation

1. Clone the repository:

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>

cd NetGuard
```

2. Create a virtual environment:

```bash
python -m venv venv
```

3. Activate the virtual environment:

Windows:

```bash
venv\Scripts\activate
```

4. Install the required packages:

```bash
pip install -r requirements.txt
```

## Run NetGuard

NetGuard requires two terminals.

### Terminal 1 - Start Network Monitoring

Activate the virtual environment:

```bash
venv\Scripts\activate
```

Run the packet capture and intrusion detection system:

```bash
python packet_capture.py
```

The system will begin monitoring network traffic.

Example:

```text
======================================================================
          NETGUARD - NETWORK INTRUSION DETECTION
======================================================================

Database initialized successfully.
Detection engine initialized.
Alert cooldown: 30 seconds

Monitoring network traffic...
Press Ctrl+C to stop.
```

Keep this terminal open.

### Terminal 2 - Start the Dashboard

Open a new terminal and activate the virtual environment:

```bash
venv\Scripts\activate
```

Start the Flask application:

```bash
python app.py
```

You will get something like:

```text
Running on http://127.0.0.1:5000
```

Open the displayed address in your browser.

## Port Scan Detection

NetGuard analyzes TCP SYN connection attempts.

If a source IP attempts to connect to multiple unique destination ports within a short period of time, the system identifies the activity as a possible port scan.

Example:

```text
PORT_SCAN

Source: 192.168.1.100
Severity: HIGH
Unique Ports: 10 within 10 seconds
```

## ICMP Flood Detection

NetGuard monitors the number of ICMP packets generated by each source IP.

If the packet count exceeds the configured threshold within the detection time window, NetGuard generates an ICMP flood alert.

Example:

```text
ICMP_FLOOD

Source: 192.168.1.200
Severity: HIGH
Packets: 15 within 10 seconds
```
